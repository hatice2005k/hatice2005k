## ⭐ Featured projects

### [ESP32 Control Panel](https://github.com/hatice2005k/esp32-kontrol-paneli)
A web dashboard that runs directly on an ESP32. It controls an RGB LED (color sequences, color picker, effects) and shows temperature, humidity and vibration sensor data in the browser. No external server needed.

`C++` · `PlatformIO` · `ESP32` · `HTML/CSS/JS`

### AQUILA: UAV Ground Control Station 🥈
Ground control software for UAVs, built with a MAVLink communication layer over UDP, TCP and Serial. Telemetry runs in separate worker threads so the PyQt6 interface never freezes, with fault-tolerant error handling. **2nd place at TEKNOFEST (Free Category).**

`Python` · `PyQt6` · `MAVLink` · `Multi-threading`

### Computer Vision with OpenCV
Real-time image and video processing: color space conversion, filtering, thresholding, morphological operations, edge detection, contour analysis and object tracking.

`Python` · `OpenCV` · `NumPy`

### Microprocessor Design *(in progress)*
Designing a processor from scratch: instruction set architecture, ALU, register file, program counter, control unit, and verification with simulation and testbenches.

`Digital Logic` · `Computer Architecture` · `HDL`

### Games
A 2D mobile game (`Java`, `Android Studio`) and a 3D game (`C#`, `Unity`) with gameplay mechanics, animations, menus and scene management.
